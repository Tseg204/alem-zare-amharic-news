# ዓለም ዛሬ — Amharic world-news cards

Project: produce daily global-news carousels in Amharic for Instagram / TikTok.
The owner is a native Amharic speaker who reviews every card and posts manually.

## How it works
- `editions/YYYY-MM-DD/` — one folder per day (Gregorian date). Never overwrite a past day.
  - `stories.json` — brand, dates (Ethiopian + Gregorian), 5 stories (category, accent color,
    emoji icon, headline, body, 0–2 stats, note, sources, optional image,
    `speech` = [headline, body] rewritten for the ear: numbers/acronyms in words, full sentences,
    attribution kept; `cover_speech` likewise; the "ለምን ያገባናል?" note is never narrated).
  - `images/` — that day's photos only.
  - `cards/` — rendered 2160×2700 JPEGs (2× of 1080×1350, quality 95, 4:4:4; `01_cover.jpg` … `07_follow.jpg`). Generated.
  - `layers/` — per card with a photo: `*_photo.jpg` (photo only) + `*_fg.png` (header, panel, text on
    transparent) + `layers.json`. Generated by `render_cards.py`; `make_video.py` zooms only the photo
    (`PHOTO_ZOOM`), text and panel stay still. Cards without a photo zoom as a whole.
  - `credits.md` — news sources + photo credits/links. Generated.
  - `research.json` — stage 1 hand-off: candidate stories, source links, the 5 selected (format: `docs/pipeline.md`).
  - `factcheck.json` — stage 3 hand-off: every number/name/date/attribution on the cards → 2+ sources →
    verified / corrected / rejected / unclear. Written by the `fact-checker` subagent.
  - `stories.draft.json` — the AI's finished draft, saved at hand-over before the owner edits (never overwritten).
  - `run_log.json` — run log: script events (validate, render, video incl. Azure voice characters, draft saved,
    approve) + the Claude Code sessions that made the edition (tokens, web searches, subagents, cost estimate).
  - `eval.json` — draft vs approved: what the owner changed (written by approve.py via `evaluate.py`).
- `render_cards.py` — renders an edition via HTML → headless Chrome (Playwright).
  Warns `OVERFLOW!` if text doesn't fit a card.
- `validate.py` — checks `stories.json` against the rules below (structure, 0–2 stats, no quotation marks,
  no flag emoji, headline length, photo credit/source/licence — no NC/ND, no Latin letters/digits/symbols in
  `speech`, date_gc = folder date, stories not still copied from yesterday; research.json has 5 selected stories with
  2+ sources; factcheck.json has no open claims and covers every number on the cards). Runs at the start of every
  render; ERRORs stop it, WARNINGs don't. Run alone: `python3 validate.py [YYYY-MM-DD]`.
- `approve.py` — the human approval gate. Every edition is `"status": "draft"` until the owner runs
  `python3 approve.py [YYYY-MM-DD]` and types "yes"; it stores `approved_at` + a fingerprint of the stories
  and photos. Any later change makes it a draft again. `--revoke` = back to draft. **Claude never runs
  approve.py and never edits `status` / `approved_*` by hand** — approval is the owner's act.
- `evaluate.py` — measures draft quality. `--snapshot DATE` saves the draft; `evaluate.py DATE` compares
  draft vs approved (runs automatically on approval); `--summary` writes the weekly table `reports/quality.md`.
- `runlog.py` — `python3 runlog.py [YYYY-MM-DD]` collects Claude Code usage for the edition (sessions that ran
  `render_cards.py --new DATE` or wrote its stories/research/factcheck JSON) into `run_log.json` and prints it.
  Scripts log their own events automatically. Do each day's edition in its own session so usage is attributed cleanly.
- `etdate.py` — `python3 etdate.py YYYY-MM-DD` prints `date_gc`, `date_et` and the spoken date for
  `cover_speech`. Never work out the Ethiopian date by hand; validate.py checks `date_et` against it.
- `photos.py` — `photos.json` (photo-scout proposals) → `python3 photos.py DATE` lists them;
  after the owner picks, `--use 1=1 2=2 …` downloads (Commons/Unsplash/Pexels only, ≤ 2400 px) and fills `image`.
- `.claude/skills/todays-cards/` — the `/todays-cards [DATE] [--unattended]` skill: the whole daily workflow
  below, resumable at any stage. `.claude/agents/` — subagents `researcher`, `amharic-writer`, `fact-checker`,
  `photo-scout`; each gets only the date as its prompt.
- `card.css` — the card style. Change the look here, not in Python.
- `docs/` — style options and mock-ups the owner chose from (reference only).

Run:
- `python3 render_cards.py --new YYYY-MM-DD` — start a day (copies the latest stories.json)
- `python3 render_cards.py [YYYY-MM-DD]` — render (default: latest edition)
- `python3 make_video.py [YYYY-MM-DD] [--voice ameha|mekdes] [--no-voice] [--silent] [--out x.mp4]`
  — approved edition → `video/short.mp4`; draft (or changed since approval) → `video/short_DRAFT.mp4`
  with a red DRAFT banner, for review only. 1080×1920 MP4 for YouTube Shorts / Reels / TikTok from the rendered cards (card on blurred
  background, slow zoom, crossfades), with Amharic AI narration (Azure neural TTS, `narrate.py`)
  and quiet background music (default voice: Ameha, chosen by the owner 10 Nov 2026). Each card lasts as long as its narration (~100 s total).
  Writes `video/short.mp4`, `audio/` (clips + `narration.txt` = what is read) and a
  "Video audio" section in `credits.md`. Azure key/region live in `.env` (never print, copy or
  commit it). ffmpeg comes from `imageio-ffmpeg`. Run it again after any re-render.
  Narration reads: brand + date + cover_title, then headline + body of each story, then a
  "follow us" line (`FOLLOW_TEXT` in narrate.py).

## Daily workflow (what Claude should do when asked for "today's cards")
Run the `/todays-cards` skill — it carries out the steps below with the subagents (researcher → amharic-writer →
fact-checker + photo-scout in parallel → photo gate → render → video → hand-over).
Stages and hand-off files are described in `docs/pipeline.md`; each stage reads the previous file.
1. Research: start the edition with `--new`, search the web for the most important world stories of the
   last 24–48h and write `research.json` (more candidates than needed, each with 2+ source links from
   different websites; mark 5 `selected` with their card number and a reason). Include at least one
   Africa/Horn of Africa story when there is one; vary categories (world, Africa, health, economy, tech, sport).
2. Verify the facts you use against 2+ reputable sources (Reuters, AP, BBC, Al Jazeera, Africanews…)
   while writing. No unverified claims.
3. Write the Amharic into `stories.json` (date_et / date_gc too): short headline (≤ ~8 words), body 2 sentences, 1 note, and stats
   only when the story has a strong number (1–2 figures; otherwise `"stats": []` — the card then
   uses the room for bigger text). All story cards share the same panel size.
   Optional "ለምን ያገባናል?" note linking the story to Ethiopians at home/abroad.
   Use Ethiopian calendar dates in Amharic text.
4. Fact-check: run the `fact-checker` subagent (Agent tool, `subagent_type: "fact-checker"`, prompt = the
   date only — do not pass your own notes, so the check stays independent). It writes `factcheck.json`.
   Apply every `corrected` / `rejected` / `unclear` fix to stories.json, then run it again until all claims
   are `verified`. Show the owner the claims that needed fixing.
5. Propose photos (see Editorial rules), render (fix any validate.py ERRORs, read its WARNINGs), fix any OVERFLOW, look at the PNGs, then make the video
   and read `audio/narration.txt` for anything the voice would read badly (abbreviations,
   symbols, Latin-letter names — spell those in Amharic in the headline/body if needed).
6. Save the draft: `python3 evaluate.py --snapshot YYYY-MM-DD` (after all fact-check fixes, before the owner
   edits anything — this is what draft quality is measured against) and `python3 runlog.py YYYY-MM-DD`
   (show the owner time, searches and cost). Then hand over for human review (the draft video is `video/short_DRAFT.mp4`). Never present AI text as final
   without review. Tell the owner: after checking, run `python3 approve.py YYYY-MM-DD`, then
   `python3 make_video.py YYYY-MM-DD` to make the final `short.mp4` for posting.

## Editorial rules
- Neutral wording; no opinion. Be especially careful with Ethiopian/regional politics.
- No direct quotes (no «…» / quotation marks) on cards or in narration: a translated quote is no longer
  the person's exact words. Always use reported speech ("X said that …"), in headlines too, and keep the
  attribution (who said it) so a claim never reads as fact.
- Paraphrase sources; never copy article text, photos or footage. Credit sources on the card.
- Keep the AI-disclosure line on the final card.
- Flag emoji (🇿🇦 etc.) may render badly — prefer generic emoji.
- Photos are optional (`"image": {file, credit, source, position}` per story, files in the
  edition's `images/`; `source` = the Commons/licence page URL).
  Only freely licensed images: Wikimedia Commons CC0/CC BY/CC BY-SA (no NC), US-gov public
  domain, Unsplash/Pexels for generic scenes. Never agency/news-site photos or realistic AI
  images of real events. Always fill `credit` (author · source · licence). Propose each photo
  (link + licence) to the owner before downloading; nothing graphic, no identifiable victims.
- Video music: only royalty-free tracks (YouTube Audio Library, Pixabay Music) listed in
  `music/tracks.json` with source + licence (+ attribution text if required). Never commercial
  songs. Propose tracks to the owner before downloading. See `music/README.md`.
  Videos run over 60 s, so only use tracks that are NOT Content ID registered (Pixabay shows it).
- The narration is an AI voice: remind the owner to switch on the platform's AI-generated label.

## Style
"Cinematic" (chosen 10 Nov 2026 — cover A + story variant 2 in `docs/mockups_cinematic/`):
- Story cards: edge-to-edge photo with the header on it, fading to black toward the bottom; a dark
  frosted-glass panel (blurred, no border, white text) overlaps the photo — same position and size on
  every story card. Category line with dot, optional stats (only for a strong number) as coloured
  numbers between thin rules, note with a tag (ማስታወሻ, or ለምን ያገባናል? when the note starts with that).
  (The earlier white-panel look is kept in the mock-ups in `docs/`; chosen change 10 Nov 2026.)
- Cover: the lead story's photo full-bleed, big Ethiopian date, lead headline, thumbnails of the
  other stories. Set `"lead": N` in stories.json (N = story number, 1–5); default is the first
  story with a photo. Pick a story with a strong, non-graphic photo.
- Follow card: blurred lead photo, brand name, AI-disclosure line.
- Every story should have a photo; without one the card falls back to a colour block + emoji.
- Photos get a light automatic tone adjustment at render time (contrast +11%, colour +20%, no sharpening,
  no retouching; settings `ENHANCE` in render_cards.py, originals in `images/` untouched). `credits.md` notes
  the photos are adjusted and cropped.
No Ethiopian-flag colours.
